# phpLDAPadmin Helm Chart

[github]: https://github.com/osixia/helm-charts

[![GitHub Stars](https://img.shields.io/github/stars/osixia/helm-charts?label=github%20stars&style=flat-square)][github]
[![Contributors](https://img.shields.io/github/contributors/osixia/helm-charts?style=flat-square)](https://github.com/osixia/helm-charts/graphs/contributors)

Helm chart for [phpLDAPadmin](https://github.com/leenooks/phpLDAPadmin), a web-based
LDAP administration tool. It deploys phpLDAPadmin as a Deployment, ready to point at
an existing LDAP server such as the [osixia/openldap chart](../openldap/index.md).

![Container OpenLDAP](../../../assets/images/osixia-container-openldap.png)

## Start Here

- New to this chart? Start with the [Quickstart](quickstart.md) to connect it to an
  LDAP server in a few minutes.
- Looking for a specific value? See the [Values reference](values-reference.md).

Chart source: [osixia/helm-charts](https://github.com/osixia/helm-charts/tree/main/phpldapadmin).
